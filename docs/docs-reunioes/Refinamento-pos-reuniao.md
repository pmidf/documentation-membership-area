**Usuários**: Pessoa, Filiado, Admin

&nbsp;

**Autenticação**

Login com email, senha, telefone, Local de residência, escolaridade, data de nascimento e gênero. Possibilidade de a tela de cadastro já especializar Pessoa em Filiado, necessário incluir PMI-DF se ela for filiada.  
Possibilidade de Entrar com o google.

Possibilidade de recuperar a senha por email.&nbsp;

Possibilidade de a Pessoa Ver como freemium o que o filiado tem acesso, mas não poder consumir o conteúdo como um block na página.

Integração com API do PMI do sistema toughtspot para validar se é filiado.

&nbsp;

**Perfil de usuário**

Pessoa e filiado podem cadastrar informações pessoais, mini bio, se está procurando emprego, podem adicionar uma foto, os emails que usa no sympla, se quer participar de gamificação e de email marketing.

Admin consegue ver todos as Pessoas e adicionar manualmente se ela é filiada ou se ela é voluntária. Ao adicionar a pessoa como voluntária ela vai automaticamente para a aba de organograma e precisa inserir nome do cargo e diretoria.

&nbsp;

**Clube de benefícios**

Página com o benefícios, apenas disponível para o filiado e não para a pessoa.

Os benefícios são cadastrados pelo Admin adicionando uma foto, título, legenda, código do cupom (como regatar) ou colocando um texto informativo de como solicitar o benefício.

Necessário registrar o histórico de usuário filiado que resgatou determinado benefício em banco de dados.

&nbsp;

**Calendário/Agenda de eventos**

Exibir eventos com título, legenda, data e formato do evento (filiado e pessoa consegue ver)

Exibir histórico de eventos que a pessoa já participou (filiado e pessoa consegue ver)

&nbsp;

**Área de conteúdo exclusivo**

Youtube privado do filiado, onde se exibe conteúdos que estão privados no youtube.

Admin consegue cadastrar conteúdos URL de vídeos e outras URLs assim como descrição, título.

Ter nesta área redirect para conteúdos do PMI, da mesma forma, mas centralizado, por exemplo PMBOK, cursos do PMI entre outros

&nbsp;

**ATS de vagas**

Cadastro de vagas pelo administrador com email do(a) recrutador, descrição, foto opcional, nome da empresa. URL pra ser compartilhado.

Filiado e pessoa podem ver. Não tem interação dos usuário, somente para ver.

&nbsp;

**Gamificação**

Cria badges que são para sempre e somente para filiados. Eles tem marcos por tempo: badge de filiado assim que se torna, de 1, 5 e 10 anos. Badges comemorativos como o de 2026 que tem uma missão específica para conseguir ele.&nbsp;

Criar um ranking das pessoas mais participativas em eventos.

Admin pode cadastrar badges novos, foto, descrição de como ganha-lo, e o que deve ser submetido.

O Filiado pode submeter algo para comprovar que ganhou e a aprovação ser manual pelo admin.&nbsp;

&nbsp;

**Acessibilidade**

botão de alto contraste, alt nas imagens e etc, navegação assistida e por tab, aumentar e diminuir fontes, contraste entre cores (background e foreground)
